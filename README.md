## 🚀 Exercícios desenvolvidos

### 01 — Soma de dois números

**Arquivo:** `exercicio1_soma.c`

Programa que solicita dois números inteiros ao usuário, realiza a soma e apresenta o resultado.

**Conceitos praticados:**
- Declaração de variáveis inteiras;
- Entrada e saída de dados;
- Operadores aritméticos;
- Utilização de `printf()` e `scanf()`.

### 02 — Média aritmética

**Arquivo:** `exercicio2_media.c`

Programa que recebe três notas, calcula a média aritmética e apresenta o resultado.

**Conceitos praticados:**
- Variáveis do tipo `float`;
- Operações aritméticas;
- Entrada de dados;
- Cálculos matemáticos em C.

### 03 — Conversão de temperatura

**Arquivo:** `exercicio3_temperatura.c`

Programa que recebe uma temperatura em graus Celsius e realiza a conversão para Fahrenheit.

**Fórmula utilizada:**

F = (C × 9 / 5) + 32

**Conceitos praticados:**
- Variáveis de ponto flutuante;
- Aplicação de fórmulas matemáticas;
- Operadores aritméticos;
- Formatação de números decimais.

### 04 — Área de um retângulo

**Arquivo:** `exercicio4_area_retangulo.c`

Programa que solicita a base e a altura de um retângulo e calcula sua área.

**Fórmula utilizada:**

Área = base × altura

**Conceitos praticados:**
- Entrada e saída de dados;
- Variáveis do tipo `float`;
- Operações de multiplicação;
- Formatação da saída com duas casas decimais.

## ▶️ Como executar os exercícios

Para executar os programas, é necessário ter um compilador C instalado.

Clone este repositório:

```bash
git clone https://github.com/SEU-USUARIO/exercicios-linguagem-c.git
```

Acesse a pasta do repositório:

```bash
cd exercicios-linguagem-c
```

Compile o exercício desejado. Por exemplo:

```bash
gcc exercicio1_soma.c -o soma
```

Execute o programa:

No Windows:

```bash
.\soma.exe
```

No Linux:

```bash
./soma
```

Repita o processo para os demais exercícios, alterando o nome do arquivo.
